# Znalostní korpus

V repozitáři není žádný schválený normativní korpus. Výchozí stav služby je
`not_ready`. Distribuované seed údaje jsou pouze veřejná metadata a odkazy
v [registru zdrojů](../src/law/registry.ts).

Ověřená vydání ukládá důvěryhodný administrátor do výslovně nastaveného
chráněného adresáře mimo tuto složku. Postup, formát manifestu, omezení
pokrytí a pin SHA-256 popisuje [dokumentace](../docs/knowledge.md).

Testy vytvářejí syntetické texty pouze v dočasných adresářích. Nesmějí být
importovány nebo publikovány jako právní zdroj. Automatický scraper ani
automatické publikování nejsou součástí projektu.
